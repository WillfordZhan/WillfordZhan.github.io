# 自动配料操作优化动图与博客增量设计

## 目标

补齐《自动配料页面 UX 改造》中的真实操作证据，并把后半部分从“功能罗列”改为“用户动作、系统反馈、边界与收益”的叙事；结尾允许克制地总结此次改造的产品价值。

## 录制边界

- 仅在 canary 的新建自动配料配方弹窗中临时填写与试算。
- 不点击保存、不创建配方、不修改既有记录。
- 使用隔离浏览器会话；采集完成后关闭会话。
- 每段 GIF 控制在 5 至 8 秒，只表现一个可观察的交互结果。

## 动图清单

1. 新增原料后，系统将该原料元素自动补入当前阶段的成分控制。
2. 首次填写最优值后，最低与最高值自动补齐。
3. 炉内成分目标自动带入炉后/产品阶段，并展示“一键复制炉内成分目标”。
4. 松弛推荐值悬浮后出现“应用”，点击后只更新当前输入框。
5. 点击“一键应用建议值”，展示二次确认与批量应用结果。
6. 配料计算设置默认收起、按需展开；已有真实动图，沿用。

## 文章改动

- 在“操作优化”章节中，每个动作紧随对应 GIF，说明系统自动化的触发条件与不做什么。
- 强调单向工序关系：炉内可以为炉后提供默认目标，炉后不反向污染炉内。
- 强调建议不覆盖作业指导书：单项应用和批量应用均由用户确认。
- 收尾增加一段克制总结：这不是删字段，而是把求解器能力放到用户做决策的时刻。

## 验收

- GIF 均来自实际页面状态，不伪造数据或效果。
- 文中不出现内部地址、账号、令牌、配方编号或客户数据。
- Hexo 本地构建通过；发布前仅提交文章与本次媒体资源。
